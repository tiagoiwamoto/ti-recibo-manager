# IwaRecibos Web (Angular)

Frontend migrado para **Angular** com **Bootstrap**.

## Como executar

```bash
npm install
npm run dev
```

O app sobe em `http://localhost:4200` e consome a API em `http://localhost:8080/api/v1` no modo desenvolvimento.

## Build de produção

```bash
npm run build
```

## Rotas principais

- `/` — Dashboard
- `/clientes` — Clientes
- `/recibos` — Recibos
- `/configuracoes` — Configurações
